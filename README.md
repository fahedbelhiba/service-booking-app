# Application Mobile de Gestion et Réservation de Services (2026)

Application Android développée en **Kotlin** sous **Android Studio** permettant la recherche, consultation de disponibilités et réservation de services en temps réel avec authentification et base de données **Firebase**.

## 🛠️ Stack Technique
- **Langage :** Kotlin 2.0
- **Plateforme :** Android Studio (Android SDK 34)
- **Backend & Données :** Firebase Authentication, Cloud Firestore, Realtime Availability
- **Architecture :** MVVM, Coroutines & Flow, Clean Architecture
- **Versionnement :** Git

## ✨ Fonctionnalités Clés
- Recherche multicritères de services avec filtres par catégorie, tarif horaire et notation.
- Visualisation des créneaux de disponibilité en direct.
- Réservation instantanée avec statut (`PENDING`, `CONFIRMED`, `COMPLETED`, `CANCELLED`).
- Profils utilisateurs et gestion des prestataires de services.
